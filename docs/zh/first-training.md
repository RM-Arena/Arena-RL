# W3 首次训练运行

以下所有策略都确实在共享的 Arena Rust 模拟器上使用 Stable-Baselines3 PPO 进行了优化。每个技能使用四个持久的并行 actor。移动/坡道/防守使用 32,768 条初始转移；前哨站使用 16,384 条。随后，在宿主端 JSONL 重置解析器修改之后，移动/坡道/前哨站又继续训练了 512 条转移；元数据记录了这次继续训练以及被允许的传输层改动。规则和内嵌物理引擎自始至终保持一致。

底层评估使用种子 1,000,000–1,000,031，均在训练种子之外。随机策略和学习策略运行相同的场景种子。结果仅描述这 32 个简单课程回合，并非关于完整对局的统计结论。

| 技能 | 随机策略成功 | 学习策略成功 | 随机策略平均回报 | 学习策略平均回报 |
| --- | ---: | ---: | ---: | ---: |
| 移动到指定点 | 11/32 | 32/32 | 2.03 | 11.62 |
| 通过 15° 坡道 | 0/32 | 32/32 | -3.28 | 15.48 |
| 攻击前哨站（40 伤害） | 31/32 | 32/32 | 11.94 | 13.53 |
| 拦截入侵者（40 伤害） | 32/32 | 32/32 | 12.71 | 14.13 |

作战基线本身就已经很强，因为弹道瞄准有辅助，且 40 伤害的目标很容易达成。这些结果证明训练循环可以正常工作，但并不表明作战技能更优。移动/通过坡道表现出更明显的学习提升。接下来应评估更难的瞄准、弹药、距离、伤害、移动目标和生存课程。

manager 策略在冻结前哨站/防守网络的条件下，训练了 4,096 条以一秒为单位的选项（option）转移。种子 2,000,000–2,000,031 包含 20 次局部进攻和 12 次局部拦截：进攻成功 20/20，拦截成功 11/12，总计 31/32。所选选项的准确率为 100%；剩余的失败来自执行而非选项选择。它尚未测试横跨整张地图的长距离导航或协同团队战术。

`checkpoints/w3/` 包含五个网络、元数据、完整的评估行、学习日志、随机基线、每个策略一份原生回放以及 SHA256 校验和。本地的 `runs/w3/` 保留了全部 160 份生成的评估回放。每份回放都记录了初始条件和动作。完整的优化器状态保存在每个 SB3 检查点中。

示例：

```bash
uv run arena-rl evaluate --checkpoint checkpoints/w3/move --episodes 32
uv run arena-rl evaluate-high --checkpoint checkpoints/w3/manager --episodes 32
```

这些参考检查点由一个开发中的 Arena 检出版本生成，元数据中将其记录为 dirty。文中提供了确切的源码哈希；在全新的、仅含上游代码的检出版本使用它们之前，必须先具备对应的 Arena 源码修改。嵌入相同引擎/规则且源码哈希相同的不同操作系统二进制文件是可以接受的。即使规则文件没有改变，过期的模拟器二进制文件也会被拒绝。
