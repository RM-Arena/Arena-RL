# 串联腿 305 评估 — 2026-10-18

本文记录 0.5.0 版本。当前策略库见 [0.5.1 改进结果](serial305-refinement-results.md)。

Arena-RL 0.5.0 仅控制**红方 3 号（red-3）、型号 305**。它保留了现有的 Rust 模拟器和机器人规格。当前的六策略库在对局期间冻结；DeepSeek V4.1 Flash（`deepseek-flash`，关闭思考模式）异步选择并切换目标。

机动测试包含八种有界模板变体，数量分别为 **18, 9, 17, 9, 1, 1, 3, 6**。这是在这些模板内的种子留出测试，而不是对任意地图的泛化。在空闲/随机恢复基线中，已有的机械固件同样会把串联底盘扶正。学习控制对撤退和后续继续执行有用；这些结果并不能证明策略学会了原始关节力矩控制或普适的恢复能力。射击使用显式的 SDK 弹道辅助以及较低的伤害阈值。

八项[物理原生回放回归](../../checkpoints/serial305/physical-regressions/report.json)已通过确定性验证。真实翻倒样本的直立度达到负值（约 −0.99），受伤场景使用普通弹丸和正常复活。精确的补给区墙体接触、同一 ID 下的恢复/撤退组合以及 0.4–0.5 m 的卡滞检测间隙都有自动化回归测试。执行技能期间不修补任何四元数、血量或位置。

## 最终真实 API 对局

| 种子 | 对手配置 | 胜方 | 仿真时长 / 已验证 tick | API 请求数 | 延迟中位数 / p95（s） | 错误 | 机械扶正开始 / 完成 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 9000020 | siege | 红方 | 420 s / 8400 | 92 | 1.570 / 2.192 | {} | 0 / 0 |
| 9000021 | raid | 红方 | 420 s / 8400 | 95 | 1.549 / 1.962 | {'provider_network_timeout': 2} | 0 / 0 |
| 9000022 | hunt | 蓝方 | 420 s / 8400 | 86 | 1.603 / 2.057 | {'provider_network_timeout': 2} | 1 / 1 |

这三场对局的结果为**红方 2 胜、蓝方 1 胜**，共 273 次真实 API 请求。所有对局均由 420 秒裁判系统计时结束，所有原生回放均验证了 8,400 个 tick。命令/进程连续性检查通过。错误计数：**{'provider_network_timeout': 4}**。格式错误、未知路点以及超出场地的坐标错误均为零。暂时性的服务商错误会保留当前的 RL 目标。`healthy_control` 是集成检查，而不是战术胜负/质量指标。

请求的速度为 1×，仿真控制频率为 10 Hz。墙钟时长为 675.3 s，在并行的本地验证期间错过了 1138 个墙钟截止时间。这证明了异步运行，而不是硬实时延迟保证。单台学习控制的红方步兵对阵两台已声明的脚本控制蓝方机器人（重型 2711 和 W3 3），使用正常的出生点、初始弹量、收入、伤害、购买和复活。这不是标准的全阵容对局，也不是胜率基准。

物理事件总数和每秒一次的位姿采样单独报告于 [physical-summary.json](../../evaluations/serial305-2026-10-18/physical-summary.json)。`recoveries_completed` 统计的是监督区间，这些区间可能从直立状态开始；不能将其解读为真实翻倒的次数。已阵亡机器人的翻倒样本与能够使用髋关节的存活机器人分开统计。

## 证据与早期运行

[最终报告](../../evaluations/serial305-2026-10-18/final/report.json)、[决策](../../evaluations/serial305-2026-10-18/final/decisions.jsonl.gz)、[遥测](../../evaluations/serial305-2026-10-18/final/telemetry.jsonl.gz)以及命令附属文件（sidecar）保留了源码/权重哈希、请求/返回的模型 ID、用量、延迟、目标、失败、原生回放 SHA256 以及确定性验证结果。未压缩的大型完整回放保存在本地 `runs/serial305-full-matches-final/` 下；它们未纳入 Git。导入 Arena 之前，请先解压物理 `.json.gz` 样本。

两组初步的三场系列对局保留在 `evaluations/serial305-2026-10-18/preliminary-*` 下。每组均为红方 1 胜、蓝方 2 胜，坐标错误为零，仅有暂时性的 API 超时。它们使用的是较早的机动权重和源码快照，不计入对最终策略库的测试。早先的 W3 报告属于历史记录，并非对 305 的受控消融实验，因为提示词、路由和权重也都发生了变化。一次失败的两 tick 启动探测不计入完整对局总数。

Arena-RL 在记录本文时为私有仓库；自 2026-10-19 起已公开。Arena-1 的本地前置依赖未因此次迁移而改变，仍未提交/未推送。GitHub 的常规契约 CI 可以独立运行；模拟器 CI 需要一份明确可用、包含这些本地环境接口的 Arena 源码。
