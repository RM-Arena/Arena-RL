# 战术参考策略

五个策略目录覆盖九个单 W3 目标。在解读成功计数之前，请先阅读[命令约定](../../docs/zh/llm-tactics.md)和[当前结果](../../docs/zh/extended-results.md)。这些是带辅助的局部课程，而不是完整对局的战术智能体。

- `navigation`、`combat`、`defense`：原始的 52 维特征策略，附有当前的回归报告。
- `support`：74 维特征的 2027 补给/护送/巡逻 PPO 策略。
- `flight`：74 维特征的 2026 正向/返程间隙跨越策略，在 PPO 之前由示范初始化。
- `validation`：实时调度/连续性结果以及经过验证的导航修复。

每个策略都包含权重、优化器状态、来源指纹、哈希以及训练/评估证据。具有代表性的原生 v4 回放在适用时附带命令附属文件（sidecar）。两份大型导航回归回放已用 gzip 压缩；导入/验证之前请先解压。原有的任务结果仍作为历史记录保留。当前的模拟器前置依赖仅存在于 Arena-1 本地，尚未推送；请使用对应的检出版本来加载这些权重。本仓库自 2026-10-19 起公开。
